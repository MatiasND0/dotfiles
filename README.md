# Dotfiles

Active desktop, terminal and shell configuration for this machine.

The files under `.config/` and `.local/bin/` are linked from their normal
locations in the home directory, so edits take effect immediately and appear
in this repository.

Tracked areas include Hyprland, Waybar, Kitty, Starship, SwayNC, SwayOSD,
Graphite launcher/clipboard, display settings and shell startup files.
